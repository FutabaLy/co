# 数字编码可视化实验室

[在线体验](https://futabaly.github.io/co/digital-encoding/) · [项目首页](../../README.md)

基于用户提供的 `408.html`，保留原页面交互与视觉样式。使用原生 JavaScript 和 SVG 绘制五种数字编码及参考时钟，无需后端或构建框架。

1. 输入二进制序列，选择初始电平及两种曼彻斯特编码约定。
2. 点击波形中的比特列查看推导，或启动自动演示。
3. 切换到练习页，依据题目给出的约定读取随机波形，填写 8 位答案并提交。
4. 在口诀表中对照各编码的特点。

页面中的读图练习为随机模拟题。Tailwind 样式与在线字体需要网络连接；可以直接使用浏览器打开 `index.html`。
